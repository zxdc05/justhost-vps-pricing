## ¥26.10 的「不限流量」到底限的是什么

限的是端口带宽，不是流量。

官网每个套餐的带宽后面都跟着「公平共享」四个字。300Mbps 是整台物理机上多个 VPS 分摊出来的端口上限，晚高峰能不能跑满取决于同宿主机上别人在干什么。流量本身确实不计费，官网给的换算是一个 300Mbps 端口跑满约等于每月 93TB 以上，正常建站、跑脚本、做代理根本用不到这个量级。

需要稳定带宽就得加钱。附加服务里 +10Mbps 带宽 ¥16.80/月，独享 1Gbps ¥2240.85/月。这个价格说明独享千兆不是给个人用户准备的。

这一点和主打线路的商家思路完全不同。DMIT 的 Premium 和 Eyeball 系列流量用完直接暂停服务，Tier 1 系列超量后限速到 50–100Mbps 继续跑。JustHost 不掐流量，掐的是峰值带宽。对一个月跑几百 GB、但不在意晚高峰能不能跑满 300M 的人来说，这个设计更实用；对需要稳定上行做直播推流或大文件分发的，公平共享就是隐患。

## 常见问题

**流量真的不限吗？**
流量本身不计费，但端口是公平共享的。跑满 300Mbps 一个月相当于 93TB 以上，正常用途碰不到这个量，真正会影响体验的是同宿主机上其他人的负载。

**续费会不会突然涨价？**
标准 VPS 的 8 折是循环折扣，续费同折。VPS Promo 的 ¥13.33 只有首月，别把它当基准价。

**机房选香港或日本是不是一定比美国快？**
位置不等于速度。一个没有做大陆方向优化的香港节点，晚高峰的实际延迟可能比做了优化的洛杉矶节点还高，因为国际线路的流量在电信联通侧可能被绕到别的出口。选节点前先确认这条线路有没有回国优化，位置是第二位的判断依据。

**能不能装 Windows？**
套餐页没有 Windows 相关说明，只列了 SSH 访问和 Linux 系操作。要装 Windows 的必须先和客服确认授权和镜像是否提供。

**适合什么人？**
需要多个国家节点、流量吃得多、可能要频繁换机房或换 IP 的项目。跨境业务落地、多地区测试、爬虫和脚本任务都合适。

**不适合什么人？**
主要用户在国内、对晚高峰延迟敏感、指望它当主力建站服务器的，应该去看带 CN2 GIA 或 9929 回程的套餐，预算要往上抬一档。需要自动备份和托管运维的也不合适，前者不提供，后者按小时收费。
